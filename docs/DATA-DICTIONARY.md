# 三联单与标准质量

- 三份 CSV 支持 UTF-8 BOM、UTF-8 与 GB18030。列可重排。原始行号按记录首行计。重复表头仅产生分段计数。空文件、全空白、只剩表头分别返回独立诊断。空串和 `-`、`N/A`、`NULL`、`未知` 是必填缺失。
- 计量票字段 `ticket,truck,opened,closed,start_l,stop_l,event,fuel,rho,rho_unit,temp_c`。时间带时区，转 UTC，结束必须晚于开始。读数用 L，温度用 °C。`event` 为 `normal`、`wrap` 或 `reset`。签收单为 `ticket,truck,signed_kg,document`，库存表为 `truck,movement,kind,kg`。库存类型为 `opening`、`inbound`、`closing`。签收与库存的输入 kg 须能精确量化成 g。
- 计量票和签收单分别用票号去重，库存以车辆和库存单号去重。规范后完全相同保留首行。冲突保留组内原件与行号，整组不入账。
- 计量票与签收单可带可选列 `airline`（航司归属），库存表不带。归属不参与原件比对：同票数值一致但航司不同的重复行不算数值冲突，只记为归属冲突并留待核。没有该列时整班照旧，归属核验整体不启用。归属以票面声明为准，票面未写时取同票回执的唯一航司；两处不一致、同票原件归属彼此不一致，或两处都缺，都记为 `AIRLINE_CONFLICT` / `AIRLINE_MISSING` 并留待核，不进入任何航司分册。航司名比较忽略首尾空白与大小写，展示名取票面首次出现的写法。
- 量程版本生效区间左闭右开。当前候选按修订号最大值选取。最大值有并列或起止及中途跨有效裁决变化时挂起。票的止读时刻也需要原量程仍有效。两端读数属于 `[0,量程)`。人工归零挂起。真实回卷须声明回卷并满足旧读数落顶带、新读数落底带，计算量程减旧读数加新读数。另校验单票发放上限。模型只支持一次回卷。
- 标准体积 L 等于观测体积乘 `1 − 0.0008 × (油温 − 15)`。密度接受 kg/m3、kg/L 与 g/L，先转 kg/m3 后按油种检查范围。两者相乘得到 g，使用 Decimal 四舍五入为整克。误差带取绝对下限与质量乘 ppm 后向上取整中较大者。签收差为签收减计量，绝对差等于误差带时算吻合。
- 逐车库存差额为期初加当班入车、减可信计量发放、减期末。对待证签收仍保留可信计量发放，另列缺证及差额。缺唯一库存期初或期末、或出现可定位库存坏行的车辆不参与合计，单列可信计量量。未被匹配的签收单单列。库存差与签收差分别核算。
- 批次键由三份 CSV 的摘要、量程样本摘要、规则与参数组成。清单与五个计算阶段在 SQLite 事务中同时提交。签发用规范 JSON 的 SHA-256 做完整性校验，保留异常状态，不改变计量判定。样例和温度模型用于交班数据复算演示。
- 签发分两种范围。整班证据单装全部原件、五个阶段与整车库存账；航司分册只装该航司自己的计量票、签收回执、逐票复核与对账摘要，别家票面和整车库存账不外发。分册自带 `scope`（航司与批次）与摘要（批次、规则、参数、量程样本摘要），摘要不读整班原件即可单独复验；整班原单仍按整班摘要各自复验。签发记录以批次与范围记账（整班用空串作范围），重试同一范围返回原摘要且不新增记录；不同范围互不覆盖。
